## 📌 Descripción

INNovaStock Enterprise es un proyecto de software orientado a la gestión, organización y seguimiento de procesos empresariales e industriales.

Su desarrollo busca integrar conocimientos de ingeniería de software con la experiencia práctica adquirida en el sector manufacturero.

El proyecto contempla una arquitectura modular y la evolución hacia funciones relacionadas con ERP, MES y WMS.

## 🎯 Objetivos

- Centralizar información operativa.
- Facilitar el seguimiento de procesos industriales.
- Apoyar la administración de inventarios.
- Mejorar la organización y consulta de información.
- Diseñar una solución escalable y mantenible.

## 💻 Tecnologías del proyecto

- C# y .NET
- Blazor
- HTML y CSS
- Arquitectura modular
- Integración de servicios y bases de datos

**Tecnologías contempladas para su evolución:** Flutter y Microsoft Azure.

## 🧩 Avances técnicos

Durante el desarrollo se ha trabajado en:

- Organización de una solución .NET con múltiples proyectos.
- Compilación y validación de componentes.
- Interfaces de acceso al sistema.
- Pantallas correspondientes a módulos ELDER y WIP.
- Pruebas iniciales utilizando datos ficticios.

Estas funciones se encuentran en distintas etapas de desarrollo y validación.
